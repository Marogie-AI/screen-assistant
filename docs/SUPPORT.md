# Support

## Getting help

Before opening an issue:

1. Read the setup and usage guidance in the [project README](../README.md).
2. Run `pnpm check` to verify the source build.
3. Run `pnpm install:host` after native-host changes.
4. Reload the generated extension from `about:debugging`.

Open a GitHub issue for reproducible bugs or focused feature requests. Include your macOS version, Firefox version, Node.js version, Codex CLI version, the command that failed, and sanitized error output.

Never attach private screenshots, credentials, session tokens, personal messages, or confidential webpage text. Use a synthetic test page when demonstrating capture problems.

## Scope

Community support is best-effort. The currently supported environment is macOS with Firefox 126 or newer and Node.js 20 or newer. Packaging, signing, Windows, Linux, and Chromium support are not yet available.

Security issues must follow [SECURITY.md](SECURITY.md), not the public issue tracker.
